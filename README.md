# Dr. Tajuddin Chitapure (PT) — Portfolio

Personal website of Dr. Tajuddin Chitapure, Associate Professor at MGM School of Physiotherapy: chronic pain and musculoskeletal rehabilitation, educator and speaker.

Static site (HTML, CSS, JS) built with Three.js (3D spine), GSAP ScrollTrigger and Lenis. It is hosted on GitHub Pages and needs no build step.
